# چک‌لیست نهایی‌سازی و انتشار «سیگنا» — استودیو پارسنا

> وضعیت فعلی: افزونه نسخهٔ **۲.۰.۱**، فازهای ۱ تا ۷ تمام، همهٔ آزمون‌ها و CI سبز.
> نام استودیو **پارسنا** (`parsena.ir`) — دامنه و هاست خریداری شد، منتظر راه‌اندازی.
>
> راهنما: 👤 = کار شما · 🤖 = کار من (کد/محتوا) · 👥 = با هم · ⛔ = مسدودکنندهٔ فازهای بعد

---

## فاز ۰ — تصمیم‌های کلیدی ⛔ (۱ روز · 👤)

بدون این‌ها فاز ۲ و ۶ قفل‌اند.

- [ ] **کانال فروش:** ژاکت / راست‌چین / سایت خودمان / ترکیبی
  - ژاکت: ۱۰۰٪ سهم فروش تا یک سال از انتشار (طبق صفحهٔ فروشندگان ۲۰۲۶)، لایسنس «گارد».
  - راست‌چین: تأیید فروشنده، دموی فارسی روی دامنهٔ خودتان **اجباری**، به‌روزرسانی حداکثر یک هفته بعد از آپدیت وردپرس/ووکامرس، رمزگذاری کد فقط با سرویس خودشان.
  - سایت خودمان: سود کامل، ولی اینماد + درگاه + سرور لایسنس لازم است.
- [ ] **مدل نسخه:** یک نسخهٔ پولی / Lite رایگان + Pro (با یک پرچم لایسنس، نه دو کد جدا)
- [ ] **قیمت** (و قیمت تمدید پشتیبانی/آپدیت سالانه، اگر دارد)
- [ ] **نشانی محصول:** `parsena.ir/signa` (پیش‌فرض فعلی سربرگ افزونه) یا دامنهٔ جدا
- [ ] **زمان انتقال به مخزن جدید:** پیشنهاد — قبل از شروع فاز ۲، تا کد لایسنس از روز اول در مخزن نهایی باشد

---

## فاز ۱ — زیرساخت parsena.ir (۱ تا ۲ روز · 👤 + 🤖 راهنمایی)

به محض آماده شدن هاست:

- [ ] SSL (Let's Encrypt) + ریدایرکت `http → https` و `www → بدون www`
- [ ] نصب وردپرس + زبان فارسی، پیوند یکتا «نام نوشته»
- [ ] ایمیل دامنه: `support@` و `noreply@parsena.ir`
- [ ] رکوردهای **SPF / DKIM / DMARC** (وگرنه ایمیل‌های کد به اسپم می‌روند)
- [ ] SMTP برای وردپرس
- [ ] پشتیبان‌گیری خودکار روزانه (خارج از همان سرور)
- [ ] امنیت: نسخهٔ PHP ۸.۲+، غیرفعال کردن ویرایشگر فایل، **ورود مدیر با خود سیگنا** 😉
- [ ] زیردامنه‌ها: `demo.parsena.ir` (دموی زنده)، `docs.parsena.ir` یا `/docs` (مستندات)، در صورت نیاز `staging`
- [ ] آمار بازدید (ترجیحاً سازگار با ایران، مثلاً Matomo روی همان هاست)

## فاز ۲ — تکمیل محصول (۵ تا ۸ روز · 🤖، آزمون حساب واقعی 👥)

### ۲.۱ کد جدید
- [ ] **حالت دمو** 🤖 — الان وجود ندارد و برای دموی زنده لازم است:
  - هیچ پیامکی ارسال نشود، کد ثابت یا نمایش کد روی صفحه
  - پنل مدیریت قابل‌گشت‌زدن ولی ذخیره‌نشدنی (یا بازنشانی خودکار هر ساعت)
- [ ] **ماژول لایسنس** 🤖 — الان وجود ندارد:
  - یک رابط، چند پیاده‌سازی: ژاکت (گارد) / راست‌چین / سرور خودمان
  - فعال‌سازی روی دامنه، بررسی دوره‌ای، رفتار مهربان هنگام قطعی سرور لایسنس (افزونه نباید سایت مشتری را از کار بیندازد)
- [ ] **به‌روزرسانی خودکار** 🤖 (اگر فروش از سایت خودمان باشد؛ مارکت‌ها سیستم خودشان را دارند)
- [ ] تفکیک Lite/Pro 🤖 (فقط اگر در فاز ۰ انتخاب شد)
- [ ] بخش «درباره/پشتیبانی» در پنل با پیوند مستندات 🤖 (بدون شماره/آیدی شخصی — قانون راست‌چین)

### ۲.۲ آزمون با حساب‌های واقعی ⛔ 👥
تا الان سامانه‌ها با شبیه‌سازی پاسخ‌های مستند رسمی آزموده شده‌اند، **نه با ارسال واقعی**.
- [ ] 👤 تهیهٔ حساب آزمایشی + کمی اعتبار و ساخت الگو (پترن) در هر سامانه:
  - [ ] sms.ir  - [ ] کاوه‌نگار  - [ ] ملی پیامک  - [ ] آی‌پی‌پنل  - [ ] فراز اس‌ام‌اس/ایران‌پیامک
- [ ] 👤 کلیدهای کپچا: - [ ] reCAPTCHA v3  - [ ] hCaptcha  - [ ] آرکپچا
- [ ] 👥 ارسال واقعی کد، سناریوی خطا (کلید غلط، اعتبار صفر، الگوی غلط) و سوییچ به سامانهٔ پشتیبان
- [ ] 👥 ایمیل OTP از طریق SMTP واقعی

### ۲.۳ سازگاری روی هاست واقعی 👥
- [ ] هاست اشتراکی ایرانی (LiteSpeed/cPanel/DirectAdmin) — همین هاست پارسنا
- [ ] پوسته‌ها: وودمارت ✅، فلت‌سام، پورتو، آسترا، هلو + المنتور
- [ ] افزونه‌های کش: LiteSpeed Cache، WP Rocket
- [ ] افزونه‌های امنیتی: Wordfence، iThemes/Solid Security
- [ ] هم‌زیستی/مهاجرت از افزونه‌های OTP رایج (مثلاً Digits) — ابزار واردسازی موجود است، روی دادهٔ واقعی آزموده شود

### ۲.۴ انتشار نسخهٔ ۲.۱.۰ 🤖
- [ ] changelog، شمارهٔ نسخه، بسته، ماتریس کامل QA (۷.۴/۶.۱، ۸.۳/۷.۱ + ووکامرس، ۸.۵/۷.۱)

## مسیر بحرانی و کارهای «همین حالا»

```
فاز ۰ (تصمیم) ──► فاز ۲ (دمو + لایسنس + آزمون واقعی) ──► فاز ۴ (سایت و دمو) ──► فاز ۶ (مارکت) ──► انتشار
                      ▲                                          ▲
فاز ۱ (هاست) ─────────┴──────────────────────────────────────────┘
فاز ۵ (اینماد، تأیید فروشنده) ── موازی، از امروز
```

تا آماده شدن هاست، این‌ها معطل هیچ چیز نیستند:
1. 👤 تصمیم‌های فاز ۰
2. 👤 اقدام برای **اینماد** و ثبت‌نام فروشنده در مارکت
3. 👤 تهیهٔ حساب‌های آزمایشی سامانه‌های پیامکی و کلیدهای کپچا
4. 👤 سفارش لوگو (یا 🤖 پیش‌نویس)
5. 🤖 ساخت حالت دمو و ماژول لایسنس
6. 🤖 نوشتن مستندات و متن صفحهٔ فرود

**برآورد کل:** حدود ۳ تا ۴ هفتهٔ کاری، که بیشترش صرف انتظار برای تأییدهای بیرونی (اینماد، مارکت) می‌شود، نه کد.
