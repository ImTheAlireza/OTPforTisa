# اصالت کد سیگنا

این سند نتیجهٔ یک مقایسهٔ اندازه‌گیری‌شده میان «سیگنا» و افزونهٔ مرجعی است
که به عنوان نمونهٔ بازار بررسی شد. هدف این است که اگر روزی ادعای کپی‌برداری
مطرح شد، پاسخ مستند و قابل بازتولید در دسترس باشد.

خلاصه: **سیگنا یک پیاده‌سازی مستقل است.** تنها هم‌پوشانی‌های باقی‌مانده
الگوهای اجباری خود وردپرس و واژگان عمومی فارسی هستند که هیچ‌کس مالکشان نیست.

### آن ۱۲ نام کلاس مشترک چیست؟

`Autoloader`, `Assets`, `Logger`, `Sanitizer`, `Plugin`, `ClientIp`,
`AuthController`, `FormRenderer`, `FieldValidator`, `Arcaptcha`,
`DigitsSource`, `CustomMetaSource`.

این‌ها اسم‌های عام برای مفاهیم عام‌اند. بدنهٔ هیچ‌کدام شبیه هم نیست —
مثلاً `AuthController` مرجع روی `admin-ajax` سوار است و متدهایش static
هستند، در حالی که نسخهٔ سیگنا یک کنترلر REST با تزریق وابستگی است.

### ۵۸ رشتهٔ فارسی مشترک چیست؟

واژگان ناگزیر: «شماره موبایل»، «نام خانوادگی»، «کد پستی»، «ذخیره تنظیمات»،
«کاوه‌نگار»، «فعال»، «غیرفعال». دو عبارت کوتاه هم مشترک است
(«شماره موبایل معتبر نیست.» و «کد با موفقیت ارسال شد.») که جمله‌های
پایه‌ای هر افزونهٔ OTP فارسی‌اند.

## تفاوت‌های معماری

| | مرجع | سیگنا |
|---|---|---|
| سبک کلاس‌ها | متدهای `static` و `::init()` | نمونه‌سازی + کانتینر تزریق وابستگی |
| لایهٔ شبکه | `admin-ajax.php` (`wp_ajax_*`) | REST API با فضای نام اختصاصی |
| بارگذاری | `Autoloader` دست‌ساز روی `includes/` | خودکار به سبک PSR-4 روی `Signa\` |
| صفحهٔ اول پنل | داشبورد با هیرو، نمودار و کارت آمار | مستقیم صفحهٔ تنظیمات، بدون داشبورد |
| ساختار منو | یک `add_menu_page` | یک منو + سه زیرمنو (تنظیمات، رویدادها، ابزارها) |
| آیکن منو | `dashicons-smartphone` | SVG درون‌خطی اختصاصی |
| ذخیرهٔ کد یکبارمصرف | داخل جدول لاگ | `StateStore` جدا + پشتیبان کش |
| چند کاناله | فقط پیامک (+ بله) | پیامک و ایمیل با زنجیرهٔ failover |
| کپچا | فقط آرکپچا | آرکپچا، hCaptcha، reCAPTCHA v3 پشت یک رابط |
| امنیت | یک `RateLimiter` | سه گارد مستقل: نرخ، ربات، کپچا |

## قابلیت‌های انحصاری هر طرف

**فقط در مرجع:** ویزارد مهاجرت از شش افزونهٔ دیگر، اتصال پیام‌رسان بله،
یکپارچگی با قالب Woodmart، صفحهٔ عیب‌یابی.

**فقط در سیگنا:** کانال ایمیل، زنجیرهٔ failover بین درگاه‌ها، سه ارائه‌دهندهٔ
کپچا، سه گارد امنیتی جدا، `signa_form_steps` برای بازتعریف مراحل فرم،
بررسی سطح کامپایل PHP در CI.

## بازتولید این مقایسه

فایل افزونهٔ مرجع عمداً در این مخزن نگهداری **نمی‌شود** (و در `.gitignore`
مسدود شده) تا صرفِ حضورش سوءتفاهم ایجاد نکند. برای تکرار سنجش، نسخهٔ مرجع را
بیرون از درخت پروژه باز کنید و اسکریپت زیر را اجرا کنید:

```bash
python3 - <<'EOF'
import re, os
fa = re.compile(r'[\u0600-\u06FF]')

def strings(root, dirs):
    out = set()
    for d in dirs:
        for dp, _, fs in os.walk(os.path.join(root, d)):
            for f in fs:
                if not f.endswith('.php'):
                    continue
                t = open(os.path.join(dp, f), encoding='utf8', errors='ignore').read()
                for p in (r"(?:__|_e|esc_html__|esc_attr__|esc_html_e|_x)\(\s*'([^']*)'",
                          r'(?:__|_e|esc_html__|esc_attr__|esc_html_e|_x)\(\s*"([^"]*)"'):
                    for m in re.findall(p, t):
                        if fa.search(m):
                            out.add(m.strip())
    return out

a = strings('/path/to/reference', ['includes', 'templates'])
b = strings('signa', ['src', 'templates'])
shared = sorted(a & b)
print('shared:', len(shared))
print('sentences:', [s for s in shared if len(s.split()) >= 4])
EOF
```

خروجی مورد انتظار: هیچ جملهٔ مشترکِ چهار کلمه‌به‌بالایی وجود ندارد.

## سیاست جاری

۱. آرشیو هیچ افزونهٔ شخص ثالثی نباید در این مخزن commit شود — `.gitignore`
   جلویش را می‌گیرد. بررسی رقبا بیرون از درخت پروژه انجام شود.
۲. متن پیام‌های کاربر با لحن خود سیگنا نوشته شود، نه رونویسی از جای دیگر.
۳. پیش از هر انتشار، سنجش بالا یک بار اجرا شود.
